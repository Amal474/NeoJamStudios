# NeoJamStudios
Official website for NeoJamStudios, with a home page and a privacy policy. It is a static site for Cloudflare Pages and has no build step.

- `index.html`: the home page (studio intro and games)
- `privacy-policy.html`: the list of games with privacy policies
- `pathfinder-privacy-policy.html`: the PathFinder privacy policy
- `maezo-privacy-policy.html`: the Maezo privacy policy
- `jelbow-privacy-policy.html`: the Jelbow privacy policy
- `spawngroundsurvival-privacy-policy.html`: the SpawnGroundSurvival privacy policy
- `style.css`: the shared styles
- `logo.png`: the studio logo (the puzzle-pawn icon), used in the nav and as the Apple touch icon
- `favicon.png`: the site favicon (the studio logo)
- `banner.jpg`: the home page hero and social share image
- `banner-mobile.jpg`: the hero on phones, cropped to the logo lockup
- `stars.svg`: the starfield tile behind every page
- `pathfinder-icon.png`: the PathFinder game icon
- `maezo-icon.png`: the Maezo game icon
- `jelbow-icon.png`: the Jelbow game icon
- `spawngroundsurvival-icon.png`: the SpawnGroundSurvival game icon
